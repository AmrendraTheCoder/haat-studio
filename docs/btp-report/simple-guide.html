Part 1. The whole story in simple words

The problem

A small seller sells clothes on Instagram. She has a photo of a kurta lying on a bed. A buyer wants to see it on a person. Hiring a model and a photographer costs money. So we want a computer to make that photo: take a picture of the garment, take a picture of a person, and make a new picture of that person wearing that garment. This is called virtual try-on.

The model I picked

Many try-on models exist. I compared eight of them. I picked one called FASHN VTON 1.5, made by a company called FASHN AI. I picked it for four reasons: it works with a garment lying flat, it is free to use even for business, it has a free website where it runs, and it keeps small details like printed text.

This model is big. It has 972 million numbers inside it. These numbers are called parameters. Think of them as 972 million tiny dials. The company set all these dials by training the model on millions of photos.

The gap I found

The company gave everyone the model and the code to use it. They did not give the code to train it. They did not write a paper about it. So anyone can use the model, but nobody outside can teach it something new. And it has never been taught sarees or lehengas.

This is like getting a finished dish from a restaurant, with no recipe.

What I did

I did four things.

  1. I studied the model. I read its code and wrote down how it works, part by part.
  2. I worked out the recipe. The code that makes a picture gives clues about how the model was trained. From those clues I wrote the training method myself. Then I tested it on the real model, and the test shows my recipe is the right one.
  3. I built the teaching tool. I used a method called LoRA. It lets me teach the model new things by adding small new parts, without changing the 972 million dials. I ran it once on the real model to show that it works.
  4. I built a website around it and checked how good the pictures are.

What is not done yet

I have not yet taught the model Indian clothes. For that I need a few hundred pairs of photos from sellers and a stronger computer. My laptop is too small for it. So I cannot say "my work made the pictures better". I can say "I built and tested everything needed to do it".

How the model makes the picture, in simple words

Think of a painter who starts with a canvas full of random dots, like TV static. The painter looks at two things: the photo of the person and the photo of the garment. Then the painter cleans the canvas a little. Then looks again and cleans a little more. After 30 rounds of cleaning, the static has become a clear photo of the person wearing the garment.

How does the painter know what to paint on the chest? Both photos are cut into small squares, like a jigsaw. Every square of the person can look at every square of the garment. The chest square looks at the logo square and copies it. This looking is called attention. Nothing is cut out or pasted. The model simply reads the garment while it paints.

How LoRA works, in simple words

Think of the model as a thick textbook. I do not want to rewrite the book, because I would spoil it. So I leave every page as it is and stick small notes on 96 of the pages. Only the notes are new. The notes are tiny: about 1% of the size of the book. If the notes are bad, I can peel them off and the book is as before.

"The model is not mine. FASHN AI made it. My work is that I understood it, I rebuilt the training method they did not share, I proved it is right, and I built the tool to teach it new clothes. I also built a working website and measured the quality. The teaching itself, on Indian clothes, is the next step."

Code 1: The LoRA layer (the most important one)

File: ml/haat_ft/lora.py, lines 36 to 53

class LoRALinear(nn.Module):
    def __init__(self, base, rank, alpha, dropout=0.0):
        self.base = base
        self.base.requires_grad_(False)      # the original layer is frozen
        self.scale = alpha / rank
        self.down = nn.Linear(base.in_features, rank, ...)    # this is A
        self.up   = nn.Linear(rank, base.out_features, ...)   # this is B
        nn.init.zeros_(self.up.weight)       # B starts at zero

    def forward(self, x):
        delta = self.up(self.down(x)) * self.scale
        return self.base(x) + delta          # original answer + small correction

What it means: base is the original layer. The line requires_grad_(False) locks it. down and up are the two small new parts, A and B. The last line is the whole idea: the output is the old answer plus a small correction. Because B starts at zero, the correction is zero at the start, so the model behaves exactly as before.

"This is the adapter I showed on slide 6. The original layer is locked here. These two are the new small parts. This last line adds the correction to the old answer."

Code 2: Putting the adapter on 96 layers

File: ml/haat_ft/lora.py, lines 68 to 77

def inject_lora(model, rank=16, alpha=16.0, targets="attn+mlp"):
    model.requires_grad_(False)              # lock the whole model
    names = [n for n, m in model.named_modules()
             if isinstance(m, nn.Linear) and pattern.search(n)]
    for n in names:
        _set(model, n, LoRALinear(model.get_submodule(n), rank, alpha))
    return names

What it means: first it locks the whole model. Then it finds the layers I chose (the attention and MLP layers) and wraps each one in the adapter from Code 1. On the real model it finds 96 layers.

Code 3: The training method I worked out

File: ml/haat_ft/flow.py, lines 35 to 43, and lines 81 to 83

def sample_t(n, device, mu=1.5):
    return torch.sigmoid(torch.randn(n) - mu)     # pick how noisy the picture is

def flow_targets(image, t, noise):
    return (1 - t) * noise + t * image,  image - noise
    #      the mixed picture             what the model must answer

# inside flow_loss:
w   = batch["weight"] * (1 + (garment_weight - 1) * batch["garment_mask"])
err = (pred - v) ** 2 * w

What it means: to train, I take a real photo and mix it with random dots. t says how much photo and how much dots. The model must answer "photo minus dots", which is the direction from dots to photo. The last two lines are the error. w is the weight: garment pixels get 2, other pixels get 1, and the empty border gets 0. That "2" is my own choice.

"This file is the recipe they did not share. This line mixes the photo with noise. This is what the model has to predict. And here the garment pixels count double."

Code 4 (extra): The proof

File: ml/scripts/check_real_model.py, lines 103 to 116. Result file: ml/runs/real-check/report.json

def reversed_time(image, t, noise=None):     # the opposite method
    return t * noise + (1 - t) * image,  noise - image

report["loss_by_t"] = {"ours": losses(flow.flow_targets),
                       "reversed": losses(reversed_time)}

What it means: it measures the real model's error with my method and with the opposite method. Open report.json and show the two rows of numbers: mine are about 0.004 to 0.012, the opposite ones are about 4 to 6.

Part 7. Hard words made easy

WordEasy meaning
ModelA computer program that has learned from examples
ParameterOne number inside the model that was set by learning. A tiny dial.
TrainingShowing examples to the model so its dials move to the right place
Fine-tuningA little more training on new examples, to teach something extra
InferenceUsing the model to get an answer. No learning happens.
Token / patchOne small square of the picture, turned into numbers
AttentionEach square looking at the other squares and taking what it needs
TransformerA kind of model built from many attention layers
DiffusionMaking a picture by starting from random dots and cleaning step by step
Rectified flowA simple kind of diffusion that goes from dots to picture in a straight line
GuidanceA small push at each step so the result follows the garment more
PoseThe body position, drawn as a stick figure
LoRASmall new parts added beside the old layers. Only they learn.
AdapterThose small new parts. Saved as a small file.
Rank (16)How big the small new parts are. Bigger learns more and costs more.
FrozenLocked. It does not change during training.
LossA number that tells how wrong the model is. Smaller is better.
GPUA chip that does this kind of maths very fast
Flat-layA photo of a garment lying flat, not worn
Open sourceShared freely so anyone can see it and use it
