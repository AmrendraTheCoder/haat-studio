# 03 · Screen by screen

For each screen: its one job, what's on it, and why.

## Home `/`

**Job:** make a sceptical seller believe it works, in one glance.

| Element | Why |
|---|---|
| Headline "your product, on a model." | Says the outcome, not the technology. No "AI" in the headline. |
| Draggable before/after of a **real** result | Proof beats claims; dragging it is the first interaction, and it's fun. |
| Product-photo thumbnail tucked beside it | Shows the input that produced it — "from this, that". |
| "Try it free" + "No card" line | Removes the two first objections: cost and commitment. |
| Three tools: photo, post, plan | The whole product in three words, each a door. |
| "Real results only" examples | Honesty as a feature. Empty slots say so; nothing is mocked. |
| "What it costs to run: ₹0" | Answers the question every small seller asks first. |
| Roadmap | Shows the professor (and sellers) where it's going, with honest statuses. |

## Studio · Step 1 — Product `/studio`

**Job:** get one usable garment photo and one fact about it.

| Element | Why |
|---|---|
| Stepper: Product → Model → Photo | Shows how long this is (three steps) and where you are. |
| Large drop zone: tap, drop or paste | Tap is the phone path; drop and paste are the laptop path. One target for all three. |
| Checks run **before** upload | A seller on mobile data shouldn't upload 10 MB to be told it's HEIC. |
| Three samples | A first-time user can try it without a photo handy. Each sample sets its category and a matching model. |
| Category is **required, no default** | A wrong category wastes a generation; a default would be wrong a third of the time. |
| Photo type defaults to "Flat or on a hanger" | It's the common case for sellers; one tap to change. |
| "For the most faithful result" tips | Teaches what a good photo is at the moment it matters, not in a manual. |
| Sticky Continue bar on phones | The main action stays under the thumb; the reason it's disabled sits right under it. |

## Studio · Step 2 — Model

**Job:** pick who wears it, knowing what each choice will do.

| Element | Why |
|---|---|
| Model cards with a plain-language note | "Wearing a dress: good for tops and dresses, not for skirts." Learned from a real failure. |
| ✓ / ✗ "suits tops" on every card | The compatibility is visible before choosing, not after a wasted try. |
| Mismatch warning with one-click switch | Explains *why* (no separate bottom to replace) and fixes it in one tap. |
| "Your own model" upload with guidance | Sellers who have a person photo can use it; the tip says what kind works. |
| Quality hidden behind "Change" | Most people should never think about it; the default is right. |
| "Takes about 15–30 seconds and uses a little of today's free GPU time" | States the cost before the click. |

## Studio · Step 3 — Working

**Job:** make a 15–40 second wait feel trustworthy.

| Element | Why |
|---|---|
| The model photo, dimmed, with a scanning shimmer | You can see what's being worked on. |
| "How it's being made" panel | Real stages from the server with real timings: upload, preparation (and what it changed), saved-photo check, GPU queue position, generation, saved. |
| "Safe to leave this page" | Removes the anxiety of not being able to switch apps. |
| Screen-reader announcement per stage | Blind and low-vision users hear progress too — once per stage, not every tick. |

## Studio · Step 3 — Done

**Job:** let the seller judge it, then post it.

| Element | Why |
|---|---|
| Before/after slider on the same model | The honest comparison: same pose, same light, only the garment changed. |
| Full screen | Details (print, neckline) need size. |
| **"Make it a post →" first** | Posting is the goal; it's the primary action. (It used to sit below the downloads — fixed after testing.) |
| "Or download just the photo" in Instagram sizes | Fitted on a blurred backdrop, never cropped — a crop could cut off the hem, which is the product. |
| Share to Instagram, WhatsApp… (phones) | The shortest path from "made" to "posted". |
| Another variation / Try another model / New product | The three things you'd naturally want next. |
| "From saved photos · no GPU used" | Builds trust that repeats are free. |

## Post maker `/studio/post`

**Job:** a finished post in under a minute, spelled right.

| Element | Why |
|---|---|
| Live preview = the download | What you see is exactly the file you get, at full resolution. |
| Product, price required; MRP, offer optional | Minimum to make a post that sells; MRP turns into "% off" automatically. |
| Shop name and handle **remembered** | The second post is three fields. |
| Three templates that never cover the garment | Panel, offer badge in a corner, frame. Text on the product hides the product. |
| Post / Square / Story | The three shapes Instagram actually uses. |
| Festive palette | Diwali is the biggest selling moment of the year. |
| Caption: tone and language (English / Hinglish) | Write the way her buyers write. |
| "Written by gemini… Read it before posting" | AI help, clearly labelled, never posted unseen. |

## Research `/research` and report `/research/<id>`

**Job:** turn ten answers into a plan she can act on this week.

| Element | Why |
|---|---|
| Five numbered sections, chips instead of dropdowns | Tappable, visible options; no hunting in menus. |
| Cost per piece optional | Not everyone knows it; those who do get exact profit maths. |
| Errors under each answer + a count by the button | You know what to fix and how much is left. |
| Answers remembered | Editing and re-running doesn't mean retyping. |
| Report labels: "Written by AI… general knowledge" vs "calculated" | Says which parts to double-check and which are exact. |
| Margin warning in plain words | "At your lowest price you keep only 20%." |
| Selling days with "in 13d" | Urgency she can act on. |
| Print / save as PDF | Meena keeps a paper copy; the professor gets a handout. |
